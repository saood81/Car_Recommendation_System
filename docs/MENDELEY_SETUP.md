# Setting Up Mendeley for This Project

The assignment requires evidence of using Mendeley for citation management, including
a screenshot of your Mendeley collection folder in the report's Appendix. Follow these
steps (~5 minutes):

1. **Create/open a Mendeley account** at https://www.mendeley.com (free) and install
   Mendeley Reference Manager (desktop or web).

2. **Create a collection folder** named e.g. `Car Recommendation NLP` (or your project
   name).

3. **Import the references** — two ways, pick whichever your Mendeley version supports:
   - **File → Import → BibTeX**, select `docs/references.bib`, **or**
   - **File → Import → RIS**, select `docs/references.ris`

   Both files contain the same 6 references used in this project:
   1. Singh et al. (2022) — Car Recommendation System Using Customer Reviews
   2. Boteju & Munasinghe (2020) — Vehicle Recommendation System Using Hybrid Recommender Algorithm and NLP
   3. Aliberti, D'Aniello & Gaeta (2026) — Situation-aware recommender systems (systematic review)
   4. Thomas & Vaidhehi (2018) — The design of web based car recommendation system
   5. Zhang, Wang & Fan (2017) — Research on passenger car recommendation based on comments mining
   6. Reimers & Gurevych (2019) — Sentence-BERT

4. **Take the required screenshot** — with the collection folder open and all 6
   references visible, take a screenshot and insert it into the report's Appendix
   (see `docs/report.docx`, Appendix section).

5. **Generate in-text citations / bibliography** — if writing directly in Mendeley's
   Word plugin ("Cite" button), select **IEEE** as the citation style
   (Mendeley → View → Citation Style → More Styles → search "IEEE"). This project's
   report already has IEEE-formatted citations and reference list matching these 6
   entries — you can either keep them as-is or regenerate them through the Mendeley
   plugin for full "evidence of use."

## Adding more references

If you add sources beyond the 6 provided here, add them to Mendeley the same way
(manually, via DOI lookup, or by dragging in a PDF — Mendeley auto-extracts metadata),
and keep `docs/references.bib` in sync by exporting your Mendeley library back to
BibTeX (**File → Export**) so the GitHub repo stays consistent with your citation
manager.
