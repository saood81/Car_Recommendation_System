# GitHub Submission Checklist

Your assignment requires more than just this one repository. Use this checklist
before submitting:

## 1. This project repository
- [ ] Push this entire folder to a new GitHub repo (e.g. `car-recommendation-nlp`)
- [ ] Confirm README.md renders correctly on the repo's main page
- [ ] Confirm `LICENSE`, `requirements.txt`, `docs/DATA.md` are all present at the
      expected paths
- [ ] Take a screenshot of the repo's main page (showing the file list + README) for
      the report's Appendix

## 2. Two or more supporting/reference repositories
The assignment asks you to add two or more repositories — reference the related work
you built on or drew inspiration from. Suggested candidates (already used as sources
in the report's literature review):
- https://www.kaggle.com/code/abdelrahmanahmed110/cars-recommendation-system
  (baseline car recommender to compare/critique against)
- https://github.com/UKPLab/sentence-transformers
  (reference implementation of the Sentence-BERT model used in this project)

You can either **fork** these into your GitHub account, or simply **star** them and
link to them from your own repo's README (already done above, under "Related work").
Check with your instructor which they expect — "add" most likely means linking/starring
plus a brief note on how each relates to your project, not necessarily a fork.

## 3. GitHub portfolio/profile
- [ ] Create or update your GitHub profile README (a special repo named exactly your
      username, e.g. `github.com/yourusername/yourusername`, with a `README.md` that
      renders on your profile page)
- [ ] Pin this project repository to your profile (Profile → Customize your pins)
- [ ] Add a short bio, skills, and links to your other projects/repos

## What to put in the report's Appendix
1. Screenshot of this repo's GitHub page
2. Screenshot of your GitHub profile/portfolio page with this repo pinned
3. Link to both, plus links to the two reference repositories above
